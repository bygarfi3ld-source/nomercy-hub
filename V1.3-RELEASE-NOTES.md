# NoMercy Clan HQ V1.3 – Main nur durch Aufstieg

- Direktbewerbungen nur für Clan 3 oder Clan 2.
- Admin-Aufstiegsleiter: Clan 3 → Clan 2 → Main. Keine automatische Beförderung, keine Erstfreigabe direkt zu Main.
- Eigene Beförderungsknöpfe im Clan-Team; jede Beförderung wird serverseitig protokolliert.
- Prüfungen verhindern Umgehung über die API, einschließlich einer Direktbewerbung und direkter Main-Freigabe.
- Bestehende Main-Mitgliedschaften bleiben unverändert.
- Kein Discord-Bot-Eingriff, keine Supabase-Anbindung, keine Änderungen an Railway-Live-Daten.
- Diese ZIP ist das lokale Release-Paket: **nicht automatisch live deployed**.

Tests: `npm test` (22 von 22 bestanden).
